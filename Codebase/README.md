Project Description
This project is a menu-driven ATM simulation system. It allows users to log in using a PIN and perform basic banking operations such as checking balance, depositing money, withdrawing money, and viewing a mini statement.


Default Account Details
Default PIN: 1234
Opening Balance: ₹10,000


Features
PIN-based login system.
Check account balance.
Deposit money.
Withdraw money.
View mini statement.
Save account balance and transactions in a file.
Handle invalid inputs and errors.

Python 3
File Handling
Functions
Loops and Conditional Statements
Exception Handling
